# Contributing to YamlQL

We welcome contributions that help make YamlQL better for everyone! Whether you're fixing bugs, improving documentation, or adding new features, your help is appreciated.

## Quick Start

1. **Fork** the repository
2. **Clone** your fork locally
3. **Create** a new branch for your changes
4. **Make** your improvements
5. **Test** everything works (see below)
6. **Submit** a pull request

## Before You Submit

Please run our test suite to ensure everything works correctly:

```bash
# Install dependencies
pip install -e .

# Run all tests
pytest

# Make sure all tests pass ✅
```

This helps us maintain code quality and prevents breaking changes from reaching our users.

## What We're Looking For

- 🐛 **Bug fixes** - Help us squash issues
- 📖 **Documentation improvements** - Make YamlQL easier to understand
- ✨ **New features** - Expand what YamlQL can do
- 🧪 **Test cases** - Improve our coverage
- 🔧 **Performance improvements** - Make YamlQL faster

## Guidelines

- **Keep it simple** - Clear, readable code is better than clever code
- **Test your changes** - New features should include tests
- **Document new features** - Help others understand what you've built
- **Follow existing patterns** - Check how similar functionality is implemented

## Need Help?

- Check existing [issues](https://github.com/AKSarav/YamlQL/issues) and [pull requests](https://github.com/AKSarav/YamlQL/pulls)
- Open an issue to discuss major changes before starting
- Ask questions in your pull request - we're here to help!

## Code of Conduct

Be respectful and constructive. We're all here to make YamlQL better together.

---

**Thank you for contributing to YamlQL!** Every improvement, no matter how small, helps make YAML analysis better for developers everywhere.
